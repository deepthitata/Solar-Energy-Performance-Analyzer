# Solar Energy Performance Analyzer

## Project Overview
The Solar Energy Performance Analyzer is an Excel-based data analysis project designed to analyze solar power generation and environmental conditions across two solar plants.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Slicers

## Key Features
- Plant-wise solar generation comparison
- Daily solar generation trend analysis
- Plant contribution analysis
- Solar irradiation analysis
- Module temperature analysis
- Interactive dashboard with Plant, Month and Year slicers

## Key Performance Indicators (KPIs)
- Total Generation
- Average Daily Generation
- Average Solar Irradiation
- Average Module Temperature

## Project Files
- `solar_energy_performance_analyzer.xlsx` – Excel dashboard and analysis
- `Solar_Dashboard.png` – Dashboard screenshot

## Conclusion
This project demonstrates how Microsoft Excel can be used for data cleaning, transformation, analysis and interactive dashboard development to understand solar energy performance.
